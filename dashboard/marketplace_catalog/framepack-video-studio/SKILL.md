# FramePack Video Studio

Use to plan a local FramePack clip or guide setup. Open Settings > Upgrades > Advanced tools > FramePack Video Studio to review hardware, downloads, saved folder and local connection. This package supplies instructions and a checklist only. It does not install, start or run FramePack.

Verify current requirements at the official repository before installation:
https://github.com/lllyasviel/FramePack

The documented baseline is Windows or Linux, a supported NVIDIA RTX 30/40/50 series GPU with at least 6 GB VRAM, and more than 30 GB of model downloads. Drivers, disk space and performance must be assessed separately. Explain download size and storage location before downloading. Paid hosting or generation needs separate approval.

For a supplied image, preserve the subject and start with one restrained motion: a slow push-in, gentle environmental movement or a static camera with subtle subject movement. Provide a concrete prompt and a short test plan. Avoid promising particular quality or speed on untested hardware.

Have the user use the official application locally with public sharing off. When execution is explicitly authorized and suitable tools exist, verify the installation and chosen workflow first; never treat a saved connection as proof the models are loaded. Save the source, prompt, seed when available, settings and output path together. Review the short result before a longer render. The output gallery is FramePack's own interface; DATA does not yet queue renders or manage video outputs.

These instructions support the user's task. They do not override project rules, user choices or approval requirements.
