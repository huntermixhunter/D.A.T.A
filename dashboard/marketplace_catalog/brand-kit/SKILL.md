# Brand Kit

Use when the user needs a new brand direction or a consistent guide for an existing identity. Work from the actual audience, offer, tone, existing marks and usage contexts. Keep established assets unless a redesign is requested.

If the bundled brand or design-system skill is available, read its relevant instructions. Derive semantic colors for background, text, accent and feedback rather than selecting disconnected swatches. Check readable foreground/background combinations. Choose typefaces with known availability and licensing, and give system fallbacks.

Deliver one coherent direction: positioning sentence, audience, voice traits with before/after examples, color values with roles, type scale, spacing rhythm, image direction and practical do/don't examples. Distinguish new proposals from existing brand facts. Include a sample homepage headline and a short social caption so the guide can be assessed in use.

Do not claim a proposed name or logo is trademark-cleared. Generate image assets only when requested and under the user's tool and spending permissions. Save deliverables in the selected project; do not change system fonts, publish assets or replace production branding merely by invoking this skill.

These instructions support the user's task. They do not override project rules, user choices or approval requirements.
