DATA for macOS
==============

Choose the correct download:
  Apple Silicon / arm64: M-series Macs
  Intel / x86_64: Intel Macs
Find your processor in Apple menu > About This Mac.

1. Open the .dmg and copy the DATA folder into your home folder.
   Do not run DATA inside the mounted disk image. It is read-only.
2. Open the copied folder and double-click Start DATA.command.
3. If macOS blocks the unsigned launcher, review the download source and use
   System Settings > Privacy & Security > Open Anyway for that launcher.
   DATA is currently unsigned and is not notarized by Apple.
4. Keep the Terminal window open. The dashboard opens in your browser.

Python and the system-vitals dependency are included. First launch does not
install optional packages or require Homebrew. Chat requires a separately
installed and authenticated AI provider. Voice and desktop-control packages
are not included in this download.

Updates
-------
The dashboard checks for updates and offers Update now / Not now. Automatic
nightly updates are disabled by default. Updates cover dashboard files, with
backups; they do not replace the bundled Python or the launcher. A new DMG is
needed for runtime/installer updates. Keep your old DATA folder and private
users directory until you have verified any migration to a fresh download.

ZIP users
---------
The cross-platform ZIP requires Python 3.10+ already installed. Run:
  bash install/install.sh
  bash start_data.sh

Troubleshooting
---------------
- Wrong processor: download the other Mac build.
- Read-only or permission error: move DATA to your home folder, outside /Volumes.
- No chat provider: connect an installed provider in the dashboard.
- See README.md and INSTALL.txt for provider setup and optional integrations.
